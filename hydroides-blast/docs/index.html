How to use this site

  1. Paste your sequence (FASTA or plain). DNA vs protein is detected automatically.
  2. Pick what to search: the genome assembly, the annotated transcripts, or the predicted proteins.
  3. Pick a program. Only the programs that make sense for your query and database are offered, and the usual choice is pre-selected.
  4. Press BLAST. GitHub opens with the search filled in; click Create. Results usually arrive in 1–3 minutes.

Reading the results

  • E-value: how many hits this good you'd expect by chance. Smaller is better; below 1e-10 is usually a real homolog.
  • Query cover: how much of your query is covered by the alignments to that sequence.
  • Identity: percentage of identical positions in the best alignment.
  • Gene: for genome hits, the annotated gene(s) overlapping the hit, or the nearest gene if the hit is intergenic.
  • The coloured graphic shows where on your query each hit aligns, coloured by score (same colours as NCBI).

Good to know

  • Searches run on GitHub's servers using the official NCBI BLAST+ programs, so results match a local BLAST.
  • Each search is a GitHub issue. Searches and results are visible to anyone who can see this repository.
  • Limits per search: 25 sequences; 200 kb total for blastn, 50 kb for blastx/blastp, 20 kb for tblastn, 10 kb for tblastx.
  • The first search after the genome is updated can take ~10–20 minutes while the databases are rebuilt.
